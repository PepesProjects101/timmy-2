# Timmy 2.0 — ESP32 Handheld Hardware Build

A custom standalone ESP32 handheld device featuring a 320×240 landscape TFT display, tactile button matrix, piezo audio, and custom C++ firmware.

## Hardware
* **Microcontroller:** ESP32 DevKit V1
* **Display:** Waveshare 2" ST7789V 240×320 TFT LCD (landscape orientation)
* **Storage & Audio:** Micro SD card reader and passive buzzer audio
* **Enclosure:** Perfboard Screwed Together
